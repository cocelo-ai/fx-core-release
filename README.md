# fx-core-release

Release package for **ARM64/AMD64 Ubuntu (py3.10/py3.11) support**.

## Download
```bash
git clone -b f16-core_0.1.7-1_arm64 --single-branch https://github.com/cocelo-ai/fx-core-release.git
```
## Install

Download the `.deb` file from the **Assets** section, then install it with:

```bash
sudo apt install ./fx-core-release/f16-core_0.1.7-1_arm64.deb
```
